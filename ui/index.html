Войдите с помощью токена

Вход пользовательским токеном в сторонний клиент нарушает правила Discord, и аккаунт могут заблокировать. С токеном бота так делать можно.

Как получить токен

Видны все ваши серверы и личные сообщения, как в обычном Discord. Нужен компьютер (браузер Chrome, Edge или Firefox).

  1. На компьютере откройте discord.com/app в браузере и войдите в свой аккаунт.
  2. Нажмите F12 (или Ctrl+Shift+I) — откроются инструменты разработчика.
  3. Перейдите на вкладку Network (Сеть). В поле фильтра напишите api.
  4. Откройте любой канал или ЛС в Discord, чтобы в списке появились запросы (например, messages?limit=50).
  5. Нажмите на любой такой запрос → вкладка Headers (Заголовки) → раздел Request Headers.
  6. Найдите строку authorization и скопируйте её значение целиком — это длинная строка из трёх частей через точку.
  7. Перешлите её себе на телефон (например, в «Избранное» мессенджера), вставьте в поле «Токен», снимите галочку «Это токен бота» и нажмите «Войти».
⚠ Важно
  • Токен = пароль от аккаунта. Никому его не отправляйте и не показывайте на скриншотах.
  • Вход токеном в сторонний клиент нарушает правила Discord — аккаунт могут заблокировать. Используйте на свой риск.
  • Если токен утёк — смените пароль Discord: все старые токены сразу перестанут работать.
  • После выхода из аккаунта в браузере токен может смениться — тогда войдите в Pocketcord заново.

Безопасно и разрешено правилами, но бот видит только серверы, куда вы его добавили. ЛС — только те, что пишут самому боту.

  1. Откройте discord.com/developers/applications и войдите.
  2. New Application → введите имя → создать.
  3. Слева Bot → Reset Token → скопируйте токен (показывается один раз).
  4. Там же включите Message Content Intent и Server Members Intent → Save Changes.
  5. Слева OAuth2 → URL Generator: отметьте bot, ниже права View Channels, Send Messages, Read Message History, Add Reactions, Attach Files, Manage Messages.
  6. Откройте получившуюся ссылку и добавьте бота на свой сервер.
  7. В Pocketcord вставьте токен, поставьте галочку «Это токен бота» и нажмите «Войти».
⚠ Токен бота тоже секретный: с ним любой сможет управлять ботом. Утёк — нажмите Reset Token.

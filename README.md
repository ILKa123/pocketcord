# Pocketcord — Discord на телефон (Rust + Tauri 2)

Клиент Discord для телефона, который выглядит как версия для ПК: слева сервера, рядом каналы, в центре чат.
Вся работа с сетью (REST и WebSocket Gateway) написана на **Rust**. Интерфейс сделан на HTML/CSS/JS без сборщиков и почти ничего не весит.

## Что умеет
- Ваши сервера, каналы с категориями и личные сообщения
- Сообщения приходят в реальном времени через Gateway, есть индикатор «печатает…»
- Markdown как в Discord: **жирный**, *курсив*, `код`, блоки кода, цитаты, спойлеры, упоминания, кастомные эмодзи, `<t:…>`
- Ответы, редактирование, удаление, реакции, вложения, эмбеды, стикеры
- **Закреплённые сообщения в 1 нажатие**: кнопка 📌 в шапке чата или свайп влево. В списке есть «Перейти» (подсвечивает сообщение, при необходимости подгружает историю) и «Открепить»
- Долгое нажатие на сообщение открывает меню: реакции, ответить, копировать, закрепить, редактировать, удалить. Двойной тап сразу открывает ответ
- Шапка как на ПК: 📞 звонок (в ЛС), 📌 закреплённые, 👤 профиль собеседника, 🔍 поиск по серверу или ЛС
- Профиль (нажатие на аватар или ник): баннер, «Обо мне», местоимения, дата регистрации, общие друзья и сервера, подключения
- Поле ввода: ➕ файлы (до 10 штук по 10 МБ, превью), GIF (поиск Discord/Tenor), 😊 эмодзи (стандартные, эмодзи сервера, недавние)
- Реакции любым эмодзи: «＋😊» в меню сообщения
- Связь с официальным Discord: тот же аккаунт и те же сообщения, отметки «прочитано» синхронизируются, «Открыть в Discord» ведёт прямо на сообщение
- Свайп вправо открывает сервера и каналы, кнопка «Назад» на Android закрывает панели
- Нажатие на сервер сразу открывает последний канал, в котором вы там были
- На планшете (ширина от 900px) всё видно одновременно, как на ПК

## Сравнение с официальным приложением
| Действие | Pocketcord |
|---|---|
| Закреплённые в текущем канале | **1 нажатие** (📌) или свайп влево |
| Другой канал этого сервера | 2 нажатия (☰ → канал) или свайп + нажатие |
| Другой сервер | 2 нажатия (☰ → сервер; последний канал откроется сам) |

## Структура
```
src-tauri/            Rust-ядро
  src/rest.rs         REST API v10, ожидание при 429
  src/gateway.rs      WebSocket: heartbeat, переподключение, фильтр событий
  src/lib.rs          команды для UI, хранение токена
ui/                   интерфейс (index.html, style.css, app.js)
ui/demo.js            демо-данные для просмотра в браузере
tools/serve.ps1       мини-сервер для демо: http://localhost:5173/?demo
```

## Сборка под Android
1. Установите **Rust**: https://rustup.rs
2. Установите **Android Studio**. В SDK Manager поставьте: Android SDK Platform, Platform-Tools, Build-Tools, **NDK (Side by side)**, Command-line Tools.
3. Задайте переменные окружения (PowerShell, затем откройте терминал заново):
   ```powershell
   [Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Android\Android Studio\jbr", "User")
   [Environment]::SetEnvironmentVariable("ANDROID_HOME", "$env:LOCALAPPDATA\Android\Sdk", "User")
   ```
   Затем `NDK_HOME` = `%ANDROID_HOME%\ndk\<версия>`.
4. Добавьте цели Rust и Tauri CLI:
   ```powershell
   rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
   cargo install tauri-cli --version "^2" --locked
   ```
5. В папке `src-tauri`:
   ```powershell
   cargo tauri icon app-icon.png
   cargo tauri android init
   cargo tauri android dev      # запуск на телефоне по USB (включите отладку по USB)
   cargo tauri android build --apk --target aarch64
   ```
   Готовый APK будет в `src-tauri/gen/android/app/build/outputs/apk/`.

Для ПК (Windows) удобно проверять так: `cargo tauri dev` в `src-tauri`.
iOS собирается так же (`cargo tauri ios init`), но нужен Mac.

## Установка
Готовый файл: **`Pocketcord-1.3.0-arm64.apk`** (Android 7+, телефоны на arm64 — почти все современные).
Скопируйте на телефон и откройте. Если Android спросит — разрешите установку из этого источника.
Отладочная версия ставится поверх без потери входа и настроек.

## Как войти (гайд по токену)
Этот же гайд есть в приложении: кнопка **«📖 Как получить токен?»** на экране входа.

### Вариант 1. Мой аккаунт — все серверы и ЛС
Нужен компьютер с браузером (Chrome, Edge, Firefox).
1. Откройте **discord.com/app** в браузере и войдите.
2. Нажмите **F12** (или Ctrl+Shift+I) — откроются инструменты разработчика.
3. Вкладка **Network** (Сеть), в фильтре напишите `api`.
4. Откройте любой канал или ЛС, чтобы появились запросы (например, `messages?limit=50`).
5. Нажмите на запрос → **Headers** → **Request Headers**.
6. Скопируйте значение строки **`authorization`** целиком (три части через точку).
7. Перешлите себе на телефон, вставьте в поле «Токен», **снимите** галочку «Это токен бота» → «Войти».


### Вариант 2. Бот — разрешено правилами, но видит только свои серверы
1. **discord.com/developers/applications** → **New Application**.
2. **Bot** → **Reset Token** → скопируйте (показывается один раз).
3. Там же включите **Message Content Intent** и **Server Members Intent**.
4. **OAuth2 → URL Generator**: `bot` + права View Channels, Send Messages, Read Message History, Add Reactions, Attach Files, Manage Messages. Откройте ссылку и добавьте бота на сервер.
5. В Pocketcord вставьте токен, **поставьте** галочку «Это токен бота» → «Войти».

Токен хранится только на телефоне, в папке данных приложения (`session.token`), и отправляется только на `discord.com`.

> ⚠ Токен = пароль от аккаунта: никому не отправляйте и не показывайте на скриншотах.
> Вход токеном в сторонний клиент нарушает правила Discord (ToS) — аккаунт **могут заблокировать**, используете на свой риск.
> Утёк токен — смените пароль Discord, старые токены сразу перестанут работать.


## Звонки
Кнопка 📞 открывает этот же чат в **официальном Discord**, и звонок идёт оттуда. Сделать звонки внутри Pocketcord сейчас нереально. Голос в Discord требует отдельного голосового сервера, UDP, кодека Opus и обязательного сквозного шифрования (протокол DAVE). Сторонние клиенты это стабильно не поддерживают.

## Поиск и GIF
Работают только при входе **пользовательским** токеном: у ботов в Discord этих функций нет.

## Что нового в 1.3
- **Настройки** — ⚙ внизу панели каналов (там же теперь «Выйти из аккаунта»):
  - **Профиль**: аватар, отображаемое имя, «Обо мне», местоимения — сохраняются в Discord;
  - **Сообщения**: размер текста, компактный режим, превью ссылок, автозапуск GIF, крупные эмодзи, отправка по Enter;
  - **Оформление**: 23 темы (светлые и тёмные градиенты) или своя картинка фоном с затемнением — видно только вам; 9 вариантов значка приложения на рабочем столе.
- Ники и аватарки всех, кто сидит в голосовых каналах (даже если там больше 100 человек).
- Ровные красные счётчики непрочитанного, убрана лишняя кнопка профиля в шапке ЛС.
## Что было в 1.2
- **Память непрочитанного**: при запуске серверы, каналы и ЛС подсвечены, как в официальном Discord, с красными счётчиками упоминаний. Прочитали на ПК — подсветка пропадает и здесь.
- **Подсказки при наборе**: `@` — люди (с поиском по нику), `#` — каналы, `:` — эмодзи. В поле видно «@Аня», а уходит настоящее упоминание.
- **Кто в голосовых каналах**: аватар, ник, выключенный микрофон или звук, LIVE у стрима. Нажатие на человека — профиль (с ролями, если вы управляете сервером), на канал — войс в официальном Discord.
- **Управление своими серверами** (если есть права):
  - нажатие на название сервера (▾) — название, иконка, новый канал / голосовой / категория;
  - долгое нажатие на канал — переименовать, тема, медленный режим, выше/ниже, удалить;
  - профиль участника → «Управление» — роли, тайм-аут, выгнать, забанить.
- **Уведомления как в Telegram**: «Ответить» прямо из шторки и «Пометить прочитанным».
- Красивые иконки групповых ЛС, категории в одну строку, значок «Pocketcord на связи» можно скрыть нажатием.

## Что было в 1.1
